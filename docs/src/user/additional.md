## Report Issues & Request Features

We welcome your feedback! Here's how you can help improve Hemulator:

### 🐛 Found a Bug?
If something isn't working correctly, please report it:
- **[Report a Bug](https://github.com/Hexagon/hemulator/issues/new?template=bug_report.yml)** - Use our bug report template

### 🚀 Have a Feature Idea?
Want to suggest a new feature or enhancement?
- **[Request a Feature](https://github.com/Hexagon/hemulator/issues/new?template=feature_request.yml)** - Use our feature request template

### 💬 Questions or General Discussion?
For questions, ideas, or general discussion:
- **[GitHub Discussions](https://github.com/Hexagon/hemulator/discussions)** - Join the community

### Before Submitting
- Search existing issues to avoid duplicates
- Provide as much detail as possible
- For bugs: include steps to reproduce, your OS, and Hemulator version
- For features: explain the use case and how it would help

Your feedback helps make Hemulator better for everyone!
