# N64 Test ROMs

This directory contains test ROMs for N64 emulation testing.

## Test ROMs Overview

### 1. Simple Test ROMs (Legacy - for basic smoke tests)

These are minimal test ROMs that verify basic RDP functionality:

- **test.z64** - Basic RDP test with colored rectangles
  - Generated by Python script (no external assembler required)
  - Draws two colored rectangles using RDP fill commands
  - Red rectangle at (50,50) to (150,150)
  - Green rectangle at (160,90) to (210,140)
  - Purpose: Quick smoke test for basic RDP rendering

- **test_enhanced.z64** - Enhanced RDP test with more complex display lists
  - Generated by `enhanced_test.py`
  - Additional RDP commands and patterns

- **test_pong3d.z64** - 3D rendering test
  - Generated by `pong3d_test.py`
  - Tests 3D triangle rendering and Z-buffer

**Note**: These simple test ROMs were created for basic smoke testing but may not work correctly in known-good emulators due to simplified RSP/RDP interactions. They are kept for basic infrastructure testing.

### 2. n64-systemtest (Recommended for comprehensive testing)

**Source**: https://github.com/lemmy-64/n64-systemtest

A comprehensive test suite that validates a wide variety of N64 features:
- CPU instructions (MFC0/DMFC0/MTC0/DMTC0, LLD/LD/SC/SCD)
- Exceptions (overflow, unaligned memory access, TRAP, BREAK, SYSCALL)
- TLB (Translation Lookaside Buffer)
- Memory access (8, 16, 32, 64 bit) to RAM, ROM, SPMEM, PIF
- RSP (Reality Signal Processor)

**Key Features**:
- Self-validating: ROM reports test results directly (no image comparison needed)
- Fast execution: Runs quickly for regression testing
- Detailed error messages: Clear indication of what's broken
- Works in known-good emulators (Project64, Mupen64Plus, etc.)

## Building Test ROMs

### Simple Test ROMs (Legacy)

```bash
# Build basic test ROM
./build.sh
```

This runs the Python script to generate `test.z64`.

### n64-systemtest (Recommended)

**Prerequisites**:
1. Install Rust: https://www.rust-lang.org/tools/install
2. Install nust64: `cargo +stable install nust64`

**Build**:
```bash
# Build n64-systemtest ROM
./build_systemtest.sh
```

This creates `n64-systemtest.n64` with the default test suite.

**Advanced builds** (from n64-systemtest directory):
```bash
cd n64-systemtest

# Build with timing tests
cargo run --release --features timing

# Build with cycle-accurate tests
cargo run --release --features cycle,timing

# Build stress tests only
cargo run --release --no-default-features --features vmulf_stress_test,vmulu_stress_test
```

See https://github.com/lemmy-64/n64-systemtest for complete documentation.

## Running Tests

### In the Hemulator GUI
```bash
# Run with simple test ROM
cargo run --profile release-quick -- test_roms/n64/test.z64

# Run with n64-systemtest (recommended)
cargo run --profile release-quick -- test_roms/n64/n64-systemtest.n64
```

### Expected Output

**Simple test ROMs**: Should display colored rectangles on screen.

**n64-systemtest**: Look for output on screen:
- Success: "Done! Tests: XXX. Failed: 0"
- Partial success: "Done! Tests: XXX. Failed: Y" (with error messages)
- Failure: Empty screen (emulator crashed or didn't boot)

## Integration with Smoke Tests

The smoke tests in `crates/systems/n64/src/lib.rs` use the simple test ROMs for basic infrastructure validation:
- `test_n64_display_list_smoke_test()` - Direct RDP command testing
- `test_n64_smoke_test_rom()` - Loads `test.z64` and verifies rendering

**Note**: These tests are marked `#[ignore]` because they require an OpenGL context and cannot run in CI.

## Troubleshooting

### n64-systemtest shows empty screen

The emulator may be missing features required for boot. See the n64-systemtest README for troubleshooting:
- https://github.com/lemmy-64/n64-systemtest#troubleshooting

Key recommendations:
1. Implement LL/SC instructions (even stub implementations help)
2. Implement DMFC0/DMTC0 (can be simplified to MFC0/MTC0 for initial testing)
3. Support ISViewer output (memory-mapped console at 0xB3FF0020-0xB3FF0220)

### Simple test ROMs don't work in other emulators

This is expected. The simple test ROMs were created for basic smoke testing in Hemulator and use simplified RSP/RDP interactions that may not match real hardware behavior. Use n64-systemtest for cross-emulator compatibility testing.
